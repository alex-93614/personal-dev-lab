# 💎 Job Finder — FF14 ジョブ適性診断アプリ

FINAL FANTASY XIV の **戦闘ジョブ全 21 種**（タンク 4 / ヒーラー 4 / 近接DPS 6 / 遠隔物理DPS 3 / キャスターDPS 4、ヴァイパー・ピクトマンサーを含む）から、あなたのプレイスタイルや好みに合うジョブを診断するローカル Web アプリです。

---

## ✨ 主な機能

1. **30 問のじっくり診断（`/quiz`）**
   - ロール志向・戦い方・操作感・チームプレイ・思考スタイル（5 段階 26 問）＋武器や雰囲気の好み（選択式 4 問）
   - 1 問ずつ進むステッパー UI（数字キー `1`〜`5` で回答、`←` / `→` で移動、途中の回答はブラウザに自動一時保存）
2. **診断結果 & 全ジョブランキング（`/result`）**
   - 1 位ジョブの詳細（キャッチコピー・解説・マッチした理由・おすすめポイント・武器・開放条件・難易度）
   - 2 位・3 位のおすすめジョブ
   - 5 ロール別の適性バー
   - 10 個の特性軸（守護 / 支援 / 火力 / 遠隔 / 魔法 / 複雑さ / バースト / 機動力 / 協調 / 計画性）の **SVG レーダーチャート**（1 位ジョブとの比較重ね表示）と **両極バー**
   - **全 21 ジョブの相性度ランキング**
   - 結果をいつでも再現できる共有 URL（コピー・回答の見直し対応）
3. **ジョブ一覧（`/jobs`）**
   - ロール別に全 21 ジョブの特徴・武器・難易度・開放条件を一覧表示

---

## 🚀 起動方法

```powershell
cd d:\Python\App\FF14_job
..\.venv\Scripts\python.exe app.py
```

（`python app.py` で直接起動しても、自動でワークスペースの `.venv` に切り替わります）

起動すると自動でブラウザが開き、`http://ff14job.localhost:5815` が表示されます。
